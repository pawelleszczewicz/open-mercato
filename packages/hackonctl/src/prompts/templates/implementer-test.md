## Test Writing Workflow

1. Identify the module and function to test
2. Read existing tests in the module for patterns
3. Write tests that cover the main behavior
4. Include edge cases where meaningful
5. Place tests in `__tests__/` directory next to the source
6. Use the same test framework (Jest) and patterns as existing tests
7. For integration tests, follow `.ai/skills/integration-tests/SKILL.md`
